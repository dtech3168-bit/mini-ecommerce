# Wizora — Fashion E-commerce Frontend

Wizora is a responsive fashion e-commerce frontend built to demonstrate modern **HTML, CSS, and JavaScript** development.

The project focuses on building a complete storefront experience, including product browsing, shopping cart interactions, promotional sections, FAQ, blog content, and responsive layouts.

> **Project status:** Frontend-only prototype. Backend, database, authentication, and real payment processing are planned for a future version.

## Cart Implementation

The current cart system is implemented entirely on the client side using JavaScript and the browser's `localStorage` API.

When a user adds a product to the cart, the selected product information is stored locally in the browser and retrieved on the cart page.

No server or database is currently required.
